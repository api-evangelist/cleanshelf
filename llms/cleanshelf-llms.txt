# Cleanshelf

> Cleanshelf was a San Francisco enterprise SaaS management platform — SaaS
> application discovery, license optimization, subscription spend tracking and
> shadow-IT detection. It was acquired by LeanIX on 24 March 2021 and relaunched
> on 1 May 2021 as LeanIX SaaS Intelligence. LeanIX was subsequently acquired by
> SAP. **Cleanshelf publishes no API today.** This file exists so an agent
> looking for a Cleanshelf API stops here instead of guessing.

Generated: 2026-09-05
Method: generated (from this repository's apis.yml and probed artifacts — Cleanshelf serves no llms.txt of its own; https://cleanshelf.com/llms.txt returns HTTP 301 to the LeanIX homepage)
Maintainer: API Evangelist (kin@apievangelist.com) — independent third-party profile, not operated by the company

## Status

- Status: acquired, retired
- Acquirer: LeanIX (24 March 2021)
- Successor product: LeanIX SaaS Intelligence (from 1 May 2021); SaaS discovery and cataloging also shipped inside the LeanIX Application Portfolio Management module
- Current operator of cleanshelf.com: SAP SE, via LeanIX — TLS certificate subject `O=SAP SE, CN=leanix.info`, nameservers `nsp1.sap.de`, `nsp3.sap.net`, `nsp4.sap.asia`
- cleanshelf.com and www.cleanshelf.com: HTTP 301 to https://www.leanix.net/
- api.cleanshelf.com, app.cleanshelf.com, docs.cleanshelf.com: do not resolve
